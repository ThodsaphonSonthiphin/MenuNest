OVERWRITEเขียนทับทิ้งของเดิมไม่มี — ดี

ทุกป้าย merge บอกเองว่าเพิ่มอะไร รอบนี้เขียนว่า adds 2 out-of-scope lines — ตรงกับที่ตั้งใจ จึงอนุมัติได้

ตัวอย่างตรงข้าม — ถ้าเผลอใส่ --force

--force ไม่ได้แปลว่า "ยืนยัน" แต่แปลว่า เขียนแผนที่ใหม่ทั้งใบ ทับของเดิม

สิ่งที่หายไปคือประวัติการตัดสินใจของ session นี้เอง — ผลสรุปของตั๋วที่ปิดแล้ว 6 ใบ, การจองตั๋ว, และเส้นบล็อกที่เพิ่งลาก ทั้งหมดถูกเขียนทับ

การซ้อมก่อนคือด่านที่ทำให้เห็นป้าย OVERWRITE ก่อนที่มันจะเกิดขึ้นจริง — และมันไม่เคยโผล่มาเองโดยไม่ได้สั่ง
